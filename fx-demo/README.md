# FX Trade Trainer（MT5スタイル FX体験アプリ）

スマホのブラウザで動く、FXのデモ取引体験アプリです。MT5（MetaTrader 5）モバイル版のUI/UXを模した画面構成で、リスクなしでFXの注文操作を体験できます。

## 使い方

`fx-demo/index.html` をブラウザで開くだけで動きます（サーバー・外部ライブラリ不要のシングルファイル構成）。

```bash
# ローカルで確認する場合
cd fx-demo
python3 -m http.server 8000
# → スマホ/PCのブラウザで http://localhost:8000 を開く
```

## 機能

- **かんたん初期設定** — 初期残高（円）をプルダウンで選ぶだけで即スタート（通貨ペアは気配値タブで選択）
- **チャート** — ローソク足チャート（M1〜D1の時間足切替、ドラッグでスクロール、ピンチ/ホイールでズーム）
- **ワンタップ注文** — チャート上部の「売 (SELL)」「買 (BUY)」ボタンで成行注文（MT5のワンクリックトレード風）
- **新規注文画面** — 成行注文／予約注文（Buy Limit・Sell Limit・Buy Stop・Sell Stop）、S/L・T/P設定
- **気配値** — 5銘柄のBid/Askをリアルタイム表示（タップでチャート切替＝通貨ペアの選択）
- **トレード** — 残高・有効証拠金・証拠金維持率・評価損益、ポジション決済、予約注文の取消
- **履歴** — 確定損益・勝敗の集計と取引履歴
- **ロスカット／S/L／T/P** — 証拠金維持率50%でロスカット執行

## 仕様

- 対応銘柄: USD/JPY, EUR/JPY, EUR/USD, XAU/USD（ゴールド）, BTC/USD（ビットコイン）
- 1ロット = 100,000通貨（XAU/USDは100オンス、BTC/USDは1BTC）、レバレッジ25倍、円建て口座
- 価格は擬似生成（慣性付きランダムウォーク）であり、実際の市場レートではありません

※ 本アプリは学習用シミュレーターです。実際の資金での取引はできません。
