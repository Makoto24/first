=== BV Booking Form（レンタカー予約フォーム） ===
Requires at least: 6.0
Tested up to: 6.7
Requires PHP: 7.4
Stable tag: 1.0.0

各店舗サイト共通で使える予約フォームプラグイン（全サイト同じZipでOK）。
中央サイト（be-village.com）のBV Rental ManagerとREST APIで連携します。

== セットアップ手順 ==

1. プラグインを有効化（各サイト共通のZip）
2. 「設定 → BV予約フォーム」で以下を設定
   - 中央サイトAPI URL: https://be-village.com/wp-json/bvrm/v1/
   - APIキー: 中央サイトの「レンタカー管理 → 設定」に表示されるキー
   - このサイトで選べる店舗（チェックボックス・複数可）
     例）白馬サイト → 白馬乗鞍店＋白馬駅前店にチェック
         松本サイト → 松本島内店＋松本信州大学前店にチェック
         大町サイト → 大町レンタカーのみチェック
   （保存すると接続テスト結果が表示されます）
   ※複数選択した場合、予約フォームの「店舗」欄でお客様が選べます。
     1つだけの場合はその店舗に固定表示されます。
     車両・予約は中央サイトで一元管理されるため在庫は全店共通です。
3. 日本語予約ページに [bv_booking_form lang="ja"] を設置
4. 英語予約ページに [bv_booking_form lang="en"] を設置

== フォームの流れ ==
1. 車両クラス・店舗・貸出/返却日時（30分単位、8:00〜21:00、本日以降）で空き確認
   - 空きあり → 概算料金と「この条件で仮予約へ進む」
   - 満車 → 日時変更の案内＋車両調整の問い合わせフォーム
2. 装備オプション・追加補償・送迎（詳細場所入力）・学割・クーポン（即時割引表示）・ご要望
3. メールアドレス→ワンタイムパスワード認証→姓名・電話・住所・生年月日・
   免許証画像（英語版はパスポート＋国際免許証）・会員登録パスワード
4. 仮予約完了（送迎なしは決済リンク付きメール、送迎ありはスタッフ確認後に決済リンク）

APIキーはサーバー側プロキシで秘匿され、ブラウザには公開されません。
