=== BV Rental Manager（Be Village レンタカー統合管理） ===
Requires at least: 6.0
Tested up to: 6.7
Requires PHP: 7.4
Stable tag: 1.0.0

be-village.com（中央サイト）に導入する統合管理プラグイン。
予約・車両・顧客・売上・業績を一元管理し、白馬・大町・松本の各サイトの
予約フォームプラグイン（BV Booking Form）とREST APIで連携します。

== セットアップ手順 ==

1. プラグインを有効化（データベーステーブルが自動作成されます）
2. 「レンタカー管理 → 設定」で以下を設定
   - 営業時間・オプション/補償料金
   - 管理者メール・CC・スタッフ通知先
   - Square: 環境(Sandbox/本番)・アクセストークン・Location ID・Webhook署名キー
   - 会社情報（社名・住所・代表者・電話・インボイス番号・社印PNGのメディアID）
   - スタッフPASS
   - 「地域サイト用APIキー」を控える（各地域サイトの設定に貼り付け）
3. 「料金カレンダー」で通常/グリーン/月額/学割料金と日別料金区分を設定
4. 「車両管理」で車両を登録（クラス・場所・装備・車検日ほか）
5. Square開発者ダッシュボードでWebhookを登録
   URL: https://be-village.com/wp-json/bvrm/v1/square/webhook
   イベント: payment.updated
6. スタッフポータル: https://be-village.com/?bv_staff=1 （設定したPASSでログイン）

== 主な機能 ==
- 予約管理（一覧・全項目編集・CSV・電話予約の追加、メール自動/手動/送信なし）
- 予約ガント（1日2マス・場所色分け・バークリックで編集・車両並び順変更・返却後も表示）
- 車両管理（1台ごと・写真4枚・車検/保険期限・月次経費・メンテ/6か月点検記録・CSV）
- 料金（24時間単位・日別料金区分の積算・月額料金・学割固定価格・クーポン）
- Square決済リンク自動生成・Webhookで予約確定・全額/50%返金
- メール（日英テンプレート編集可・OTP認証・支払リマインド）
- 印刷物（予約票・受付表・領収書、A4 1枚・日英切替・社印/インボイス印字）
- 貸渡実績報告書（年度集計・年度またぎ按分・xlsx出力）
- 経営ダッシュボード（月次推移・車両別売上/経費/稼働率）
- 会員機能（メール認証→会員登録、予約番号で確認・変更・キャンセル）

== 変更履歴 ==

= 1.30.0 — セキュリティ修正 =

セキュリティ現状調査レポート（2026年8月28日）で指摘された項目への対応です。

**免許証・パスポート画像の保護（レポート指摘1・B-1a/B-1b/B-1c）**

* 本人確認書類の保存先を、公開領域の `wp-content/uploads` 直下から
  `wp-content/uploads/bv-private/` に変更しました。このディレクトリには
  直接アクセスを禁止する `.htaccess`（および IIS 用 `web.config`）を自動生成します。
* 予約データにはURLではなく内部キーだけを保存します。閲覧は署名付き・
  2時間で失効するリンク経由となり、管理画面・スタッフポータルからの
  閲覧時にはログイン状態を配信時にもう一度確認します。
* ファイル名から用途が分からないよう `bvdoc-（ランダム24文字）` 形式に変更しました。
* 「設定」画面に、公開領域に残っている既存画像を非公開領域へ移す
  移行ボタンを追加しました（繰り返し実行しても安全です）。

**Square決済通知の本人確認（レポート指摘2・B-4b）**

* 署名キーが未設定のとき、および診断用の「署名検証を一時停止」が
  オンのときに、検証せず通知を受理していた動作を廃止しました。
* 署名を検証できない場合、通知の内容（支払済みかどうか）は信用せず、
  予約の特定にだけ使い、入金の有無はアクセストークンでSquareへ
  直接問い合わせて確認します。偽の通知で予約が確定することはありません。
* 署名キーが設定されているのに署名が一致しない通知は、従来どおり403で拒否します。
* 診断用の一時停止は、オンにしてから60分で自動的に失効するようにしました。

**その他**

* 予約取得処理の `ORDER BY` を列名のホワイトリスト方式に変更しました（C-5b）。
* スタッフポータルのログインに試行回数の制限を追加しました
  （同一端末から10回連続失敗で15分間ロック）。認証クッキーに SameSite を付与し、
  管理画面のスタッフPASS欄を伏せ字（「表示」チェックで確認可）にしました（C-11）。
* 期限切れの認証コードを1日1回自動削除するようにしました（C-13）。
* 本人確認書類の保持日数を設定できるようにしました。返却済・キャンセルの予約について
  指定日数の経過後に自動削除します（既定は0＝削除しない）（B-3）。

= 1.31.0 =

**店舗名の変更**

* 「白馬レンタカー From P出張所」を「長野カーシェアFrom P出張所」に変更しました
  （英語表記は Nagano Car Share From P Branch）。店舗キーは変更していないため、
  既存の予約・車両データへの影響はありません。拠点名と専用ポータルの表記は
  「From P出張所」のままです。BV Booking Form 1.13.2 でも同じ名称に変更しました。

**返却後のお礼・口コミ依頼メール**

* 返却処理が完了すると、お客様へお礼＋Googleマップの口コミ依頼メールを自動送信
  します。スタッフポータルの返却処理画面で、1件ずつ送らないことも選べます。
  同じ予約に2通目が送られることはありません。
* メール内の「クーポンを受け取る」リンクをお客様が押すと、その方専用の500円引き
  クーポンを発行し、コードをメールでお送りします（1予約につき1枚・1回限り・
  全店舗で利用可・発行から1年間有効）。金額と有効期間は設定画面で変更できます。
* 口コミの投稿URLは店舗ごとに異なるため、「設定 → 店舗別設定」で店舗ごとに
  入力します。URLが未設定の店舗ではメールを送信しません。
* Googleは口コミ投稿の有無を外部から確認する手段を提供していないため、受け取りは
  お客様の自己申告です。受け取りリンクには予約ごとの署名が付いており、
  他の予約のクーポンを受け取ることはできません。
* 予約詳細に送信状況とクーポンの発行状況を表示し、手動送信・再送ができます。
* クーポンに利用回数の上限を設定できるようにしました（0で無制限）。クーポン一覧に
  「利用／上限」と「発行元」の列を追加しています。
* メール文面は「メール文面」の設定から編集できます（日本語・英語）。

= 1.32.0 =

**運転者の年齢制限**

* ネット予約で、貸出日時点の満年齢が下限に満たない場合は受け付けないように
  しました。予約フォームの送信前と中央サイトの受付処理の両方で判定します
  （フォーム側の確認を迂回しても、中央側で受け付けません）。
* 下限年齢は「設定 → 運転者の年齢制限」で変更できます（既定21歳・0で制限なし）。
  予約フォームの注意書きの年齢表記も、この設定に自動で追従します。
* 判定は<strong>申込日ではなく貸出日</strong>を基準にします。申込時点で20歳でも、
  貸出日に21歳になっていれば予約できます。
* 管理画面・スタッフポータルからの予約追加は、電話での例外対応ができるよう
  制限の対象外です。

**差額の追加請求**

* 貸出期間の変更や追加補償の変更で金額が上がったとき、<strong>差額だけ</strong>を
  お客様に追加請求できるようにしました。すでにお支払いいただいた分を、
  新しい金額で再決済していただく必要はありません。
* 予約詳細に「お支払いの過不足」欄を追加しました。現在の合計・収納済み額・
  不足額（または過払い額）が一目で分かります。
* 不足がある場合、金額と理由を入れて「差額の決済リンクを作成してお客様へ送る」を
  押すと、差額分のSquare決済リンクを発行してメールでお送りします。理由欄には
  管理メモの変更履歴から推測した下書きが入ります。
* お客様の予約確認ページ（?bv_manage=）にも追加料金の案内とお支払いボタンが
  表示されます。
* お支払いはWebhookで自動反映されます。届かない場合も15分ごとの自動同期で
  最大15分ほどで反映されるほか、「Squareで入金を確認」ボタンで即時確認できます。
  現金で受け取った場合は「受領済みにする」で記録できます。
* 追加請求の取り消しもできます。
* 領収書は<strong>実際に収納した額</strong>で発行します。差額が未入金の場合は、
  その額を含めず「差額 ○○円：未収」と注記します。追加料金の入金があった場合は
  支払方法欄に記載します。
* 返金できる上限を、予約金額ではなく実際に収納した額に変更しました。金額を
  変更した予約でも、受け取った額を超えて返金されません。
* 収納済み額を記録する列を追加したため、更新時に既存の支払済み予約へ
  当時の金額を自動で書き込みます（一度きり・既存データは変更されません）。
* メール文面（追加料金のお願い／入金確認／管理者通知）は設定画面から
  編集できます。

（予約フォーム側 1.14.0：年齢制限の確認を追加。中央サイトの設定に追従します。）
