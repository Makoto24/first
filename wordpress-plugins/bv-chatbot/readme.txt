=== BV Chatbot（レンタカー問い合わせチャット） ===
Version: 0.2.0（原型）
Requires PHP: 7.4
必要なもの: 中央サイトの BV Rental Manager 1.38.0 以上（空車確認・料金カレンダーに使います）、Claude（Anthropic）のAPIキー

予約フォームとは別の、お問い合わせ専用チャットです。
・よくある質問には、管理画面で登録した「Q&A集」をもとに答えます。
・料金・営業時間・キャンセルポリシー・車両クラスは、中央サイトの設定を自動で読み込みます。
・料金表（通常料金／グリーンシーズン料金・長期割引など）と料金カレンダー（どの日がどちらの料金か）も
  中央サイトの「料金設定」から自動で読み込みます。変更はチャットに最大10分で反映されます。
・空車確認は、中央サイトの予約管理（ガントチャート）と同じ判定でその場で調べます。
・チャットから予約・変更・キャンセルはできません（予約フォーム・予約確認ページへご案内します）。

== はじめての設定（順番に） ==

1. ClaudeのAPIキーを用意する
   https://console.anthropic.com/ にログイン → 左のメニュー「API Keys」→「Create Key」。
   表示された「sk-ant-…」で始まる文字列をコピーします（あとで見られないので、すぐ次の手順へ）。
   ※同じ画面の「Billing」で支払い方法と「Spend limit（月の上限額）」を設定しておくと安心です。

2. 中央サイト（be-village.com）の BV Rental Manager を 1.38.0 以上に更新する
   （空車確認用の読み取り専用APIが追加されています）

3. チャットを置くサイトにこのプラグインを入れる
   「プラグイン → 新規追加 → プラグインのアップロード」で bv-chatbot-0.1.0.zip を選び、有効化します。
   管理画面の左に「チャットボット」が出ます。

4. 「チャットボット → 設定」
   ・Claude APIキー：手順1のキーを貼り付け
   ・中央サイトの接続先：予約フォームのプラグインが同じサイトにあれば自動で入ります（「接続OK」と出ればOK）
   ・案内する店舗：このサイトで扱う店舗にチェック
   ・予約フォームのページ・問い合わせ先（電話・メール）を入力
   ・「チャットを有効にする」はまだチェックしないで保存

5. 「チャットボット → Q&A集」
   よくある質問と答えを書きます。エクセルで作る場合は A列＝質問、B列＝回答 で
   「CSV」形式で保存し、アップロードします（文字化けしないよう自動で変換します）。
   料金・営業時間・キャンセルポリシーは自動で読み込むので、書かなくて大丈夫です。

6. 「チャットボット → 動作テスト」で質問してみる
   例：「来週の土曜10時から日曜18時まで、ミニバンは空いていますか？」
   空車確認を使ったときは、確認した内容も表示されます。

7. 問題なければ「設定」で「チャットを有効にする」にチェックして保存
   全ページの右下に「お問い合わせ」ボタンが出ます。特定のページだけに置くときは、
   右下表示のチェックを外し、そのページに [bv_chatbot]（英語ページは [bv_chatbot lang="en"]）を入れます。

8. ときどき「会話ログ」を見て、答えられなかった質問をQ&A集に追加します。

== 費用の目安と歯止め ==
・お客様の質問1回ごとに Claude API の利用料がかかります（空車確認をすると2回分ほど）。
・既定のモデルは Claude Opus 5.5（いちばん賢い）。費用を抑えたいときは設定で Sonnet 5.5 や Haiku 4.5 に変えられます。
・Q&A集が長いほど1回あたりの費用が増えます。続けて質問があるときは「キャッシュ」で安くなります。
・設定の「使いすぎ防止」で、接続元ごとの回数制限（10分間）と1日の呼び出し上限を決められます。
  設定画面に本日の利用量（呼び出し回数・トークン数）が出ます。

== 安全のための作り ==
・APIキーはこのサイトのデータベースにだけ保存し、お客様の画面には送りません（設定画面でも表示しません）。
・空車確認は読み取り専用で、予約・お客様の情報には触れません。中央サイトとの通信は予約フォームと同じAPIキーで行います。
・会話の履歴はサーバー側に保存し（2時間）、お客様のブラウザから過去のやり取りを書き換えて送り込むことはできません。
・回答はHTMLとして解釈せずに表示し、http/httpsのURLだけをリンクにします。
・会話ログにIPアドレスは保存しません。保存期間を過ぎたログは毎日自動で削除します。
・プラグインを「削除」すると、設定・Q&A集・会話ログも消えます。

= 0.2.0 =
* 中央サイトの料金表と料金カレンダー（通常料金／グリーンシーズン料金）を読み込み、
  「料金はいくら？」「12月はどちらの料金？」などに答えられるようにしました（中央サイト 1.38.0 以上が必要）。
* 日程が決まっている料金の質問は、空車確認と同じ仕組みで目安の合計額を確認します（満車のクラスも料金の目安を案内）。
* 時間貸しの店舗は、1時間あたりの料金も案内します。
* 設定画面に、料金カレンダーの連携状況と、チャットに渡している期間の一覧を表示します。
