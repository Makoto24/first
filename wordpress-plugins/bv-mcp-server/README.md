# Claude に売上や予約を聞けるようにする手順

パソコンに **Claude Desktop（デスクトップ版）** を入れて、ファイルを1つダブルクリックするだけです。
専門的な準備（プログラムの導入や設定ファイルの編集）は要りません。

できるようになること：

- 「今月の売上は？」「先月の稼働率は？」
- 「稼働率の低い車両は？ 赤字の車両はある？」
- 「明日の貸出予定は？」「未入金の予約は？」
- 「車検が近い車両は？」

**読み取り専用**なので、Claude から予約や車両のデータが書き換わることはありません。
お客様の連絡先・住所・生年月日・免許証は Claude に渡りません（予約の一覧に出るのは姓だけです）。

> **スマホのClaudeアプリやブラウザ版では使えません。** パソコンのデスクトップ版が必要です（Windows / Mac）。

---

## 手順1　Claude Desktop を入れる（すでに入っていれば飛ばす）

1. https://claude.ai/download を開く
2. お使いのパソコン（Windows / Mac）を選んでダウンロード
3. ダウンロードしたファイルを開いてインストールし、Claude にログインする

## 手順2　中央サイトで「データ連携」をオンにして、キーをコピーする

1. be-village.com の管理画面にログイン
2. 左のメニュー **「レンタカー管理」→「設定」**
3. 画面を下にスクロールして、**「スタッフポータル・API」** の欄を探す
4. **「データ連携（Claude等）」** のチェックを入れて、一番下の **「設定を保存」** を押す
5. もう一度「設定」を開くと、**「連携キー」** という英数字の長い文字列が表示されています
6. その文字列を **クリック**（全体が選択されます）して、コピーする（Windows は Ctrl + C、Mac は ⌘ + C）

> 連携キーは、パスワードと同じ扱いです。人に見せたり、メールで送ったりしないでください。

## 手順3　拡張ファイルをインストールする

1. `bv-rental-claude-1.1.0.mcpb` というファイルを、パソコンに保存しておく
2. そのファイルを **ダブルクリック**
   - 開けないときは、Claude Desktop を開いて、ファイルを **ウィンドウの中にドラッグ＆ドロップ**
3. 「拡張機能をインストール」のような画面が出るので **「インストール」** を押す
4. 設定の入力欄が出たら、次のように入れる：
   - **連携キー** … 手順2でコピーした文字列を貼り付ける
   - **接続先URL** … そのまま（変更しない）
5. 保存して、**拡張機能をオン**にする

## 手順4　使ってみる

Claude Desktop で新しい会話を開いて、こう聞いてみてください。

> 今月の売上を教えて

売上や件数の答えが返ってくれば成功です。

## うまくいかないとき

**「連携キーが違うか、データ連携が無効」と表示される**
- 手順2の **「データ連携（Claude等）」にチェックが入って、保存されているか** を確認
- キーの貼り付け間違い（前後に空白が入っている等）がないか確認して、入れ直す

**「データ連携が無効」の状態が続く／接続できない**
エックスサーバーの「国外IPアクセス制限」や「WAF」が原因のことがあります。
決済の Webhook が届かないときと同じ原因です（管理マニュアル「困ったときは」を参照）。

**キーを人に見せてしまった／パソコンを手放す**
管理画面の「設定」にある **「連携キーを作り直す」** を押してください。古いキーはすぐに使えなくなります。
そのあと、手順3の設定に新しいキーを入れ直します。

**使わなくなったとき**
管理画面の「データ連携（Claude等）」のチェックを外して保存してください。キーごと無効になります。

## 補足（詳しい方向け）

- 仕組み：Claude Desktop（お手元のPC）→ このMCPサーバー → be-village.com の `/wp-json/bvrm/v1/data/`
- Claude Desktop には実行に必要なNode.jsが最初から入っているので、別途の導入は不要です
- `.mcpb` は、`manifest.json` と `server/index.js` をまとめたZIPです。作り直すときは
  `wordpress-plugins/build.sh` を実行してください
