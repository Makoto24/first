# FX Trade Trainer（広告入り版）

`fx-demo/` と同じMT5スタイルのFX体験アプリの**広告入り版**です。設定タブに公式LINEのPRバナー・広告文・友だち追加ボタンを表示します。

- 公開URL: https://makoto24.github.io/first/fx-demo-pr/
- 広告なし版: https://makoto24.github.io/first/fx-demo/

## バナー画像について

設定タブのバナーは `fx-demo-pr/banner.png` を参照します。画像が未配置の間は、デザインをCSSで再現した代替バナーを表示します。本物の画像に差し替えるには、`fx-demo-pr/banner.png` という名前で画像をアップロードしてください（自動で差し替わります）。
