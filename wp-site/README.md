# wp-site — WordPress コンテンツ投稿ツールキット

Xserver 等で稼働中の **WordPress（レンタカー店舗サイト）** に、固定ページとブログ記事を
**REST API 経由で作成・更新**するためのツールキットです。テーマは既存のものをそのまま使えます。

- 記事・各ページの文章は `content/` 配下に Markdown（風）ファイルとして管理
- スクリプトを実行すると WordPress に反映（同じ slug があれば上書き更新）
- 依存パッケージなし（Node.js 18 以上のネイティブ `fetch` のみ）

---

## 1. 事前準備：アプリケーションパスワードの発行

通常のログインパスワードではなく、**アプリケーションパスワード**を使って安全に接続します。

1. WordPress 管理画面 → **ユーザー** → **プロフィール**
2. 下部の **「アプリケーションパスワード」** で名前（例: `wp-site-tool`）を入力して追加
3. 表示された `xxxx xxxx xxxx xxxx xxxx xxxx` を控える（再表示されません）

> アプリケーションパスワードの項目が出ない場合は、サイトが https で動作しているか、
> またはセキュリティ系プラグインで無効化されていないかを確認してください。

## 2. 接続設定

```bash
cd wp-site
cp .env.example .env
```

`.env` を編集し、以下を設定します（`.env` は Git に含まれません）。

```
WP_BASE_URL=https://あなたのサイト.com
WP_USERNAME=WordPressのユーザー名
WP_APP_PASSWORD=xxxx xxxx xxxx xxxx xxxx xxxx
```

## 3. 接続確認

```bash
npm run list
```

認証に成功すると、ユーザー名・既存の固定ページ・投稿の一覧が表示されます。

## 4. 反映する

```bash
# 中身だけ確認（送信しない・認証情報不要）
node scripts/deploy-pages.js --dry-run
node scripts/publish-posts.js --dry-run

# 固定ページを作成 / 更新
npm run deploy:pages

# ブログ記事を作成 / 更新
npm run publish:posts

# まとめて反映
npm run deploy:all
```

slug が一致する既存コンテンツは**更新**、なければ**新規作成**されます（冪等）。

## コンテンツの編集・追加

`content/pages/`（固定ページ）と `content/posts/`（ブログ記事）に Markdown ファイルを置きます。
ファイル先頭の `---` で囲んだ部分がメタ情報、その下が本文（WordPress 用 HTML）です。

```markdown
---
title: ページのタイトル
slug: page-slug            # URL の一部・更新時のキーになる（必須）
status: publish            # publish（公開） / draft（下書き）
menu_order: 1              # 固定ページの並び順（任意）
categories: お知らせ        # 投稿のカテゴリ（任意・カンマ区切り、なければ自動作成）
excerpt: 一覧用の抜粋        # 投稿の抜粋（任意）
---
<!-- wp:paragraph -->
<p>本文をここに書きます。WordPress のブロックコメント付き HTML が使えます。</p>
<!-- /wp:paragraph -->
```

- **本文は HTML** として WordPress に送られます。`<!-- wp:... -->` のブロックコメントを付けると
  ブロックエディタでもきれいに編集できます（なくても表示は問題ありません）。
- 記事を **AI で書く / 更新する** 場合は、対応するファイルを編集して再度スクリプトを実行するだけです。

## ロゴ・画像・テーマ（Astra）の設定

画像ファイルは Git ではなく WordPress のメディアに置きます。以下は管理画面での操作です。

1. **画像のアップロード**：メディア → 新規追加 で、ロゴ・ヒーロー写真（松本城＋北アルプス）・
   車両写真などをアップロード。
2. **ロゴ / サイトカラー（Astra）**：外観 → カスタマイズ →
   - 「サイト基本情報（ヘッダー）」でロゴ画像を設定
   - 「グローバル → カラー」でメインカラーを設定（ロゴに合わせて黒基調＋アクセント色）
3. **トップのヒーロー画像**：ホームページ上部に大きな写真を入れる場合は、ブロックエディタで
   ホームを開き、先頭に「カバー」ブロックを追加してアップロード済みの写真を指定するのが簡単です。
   （`content/pages/00-home.md` のキャッチコピー見出しの上に配置するイメージ）

> スクリプトはテキストコンテンツを反映しますが、画像の配置・テーマの色やロゴは
> 上記のとおり WordPress 側で設定してください。

## 予約プラグイン / フォームについて

- ホーム・ご利用の流れページには予約フォーム用の `[reservation_form]` というショートコードの
  プレースホルダーを置いています。レンタカー予約プラグイン導入後、**実際のショートコードに
  置き換えて**ください（プラグイン自体は別途作成）。
- お問い合わせページは Contact Form 7 を想定したショートコード例を置いています。
  お使いのフォームプラグインのショートコードに差し替えてください。

## フロントページ・メニューの設定（WordPress 側の操作）

スクリプトはページ／記事の中身を作りますが、以下は WordPress 管理画面で設定します。

- **トップに「ホーム」を表示**：設定 → 表示設定 → 「ホームページの表示」を「固定ページ」にし、
  ホームページに `ホーム` を指定。
- **グローバルメニュー**：外観 → メニュー で各固定ページを追加して表示位置を割り当て。
